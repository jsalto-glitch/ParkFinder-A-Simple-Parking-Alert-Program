# ParkFinder — Simple Notebook Version

A beginner-friendly parking tracker demonstration using simulated sensor readings.

## Files
- `main.ipynb`: main program notebook.
- `parking_spot.py`: parking spot class.
- `parking_tracker.py`: functions for loading data and sending alerts.
- `data/parking_spots.csv`: example parking spots.
- `data/sensor_readings.csv`: simulated sensor readings.
- `alerts_log.csv`: created when the notebook runs.

## Run
1. Extract this ZIP.
2. Open the extracted `ParkFinder_Notebook` folder in VS Code.
3. Open `main.ipynb` and select a Python kernel.
4. Run notebook cells from top to bottom.

No extra libraries are needed.

Note: locations and readings are examples only. This does not connect to live Hoboken parking sensors.
